📂 1. 디렉터리 및 주요 파일 구조와 역할
디렉터리 구조별 역할 (app/)
app/core/: 애플리케이션 전반의 핵심 설정(Configuration), 보안/인증, 공통 유틸리티 및 데이터베이스 연결 객체를 관리합니다.

app/models/: SQLAlchemy ORM 모델이 정의되는 곳으로, 실제 데이터베이스 테이블과 매핑되는 파이썬 클래스들이 위치합니다.

app/repositories/: 데이터베이스 접근(Data Access) 계층입니다. models를 이용해 실제 DB 쿼리(CRUD)를 수행하는 로직을 담당합니다.

app/schemas/: Pydantic 모델을 정의하는 곳으로, API 요청(Request) 데이터 검증 및 응답(Response) 데이터 직렬화를 담당합니다.

app/services/: 비즈니스 로직(Business Logic) 계층입니다. API 엔드포인트와 리포지토리 사이에서 핵심 비즈니스 규칙을 처리합니다.

app/apis/: API 라우터(Endpoint)들이 위치하며, 클라이언트의 요청을 받아 서비스 계층으로 전달하고 결과를 반환합니다.

주요 파일의 역할
app/main.py: FastAPI 애플리케이션의 진입점(Entry Point). 앱 인스턴스 생성, 미들웨어 설정, 라우터 등록 및 앱 생명주기(Lifespan)를 관리합니다.

app/core/config.py: pydantic-settings를 활용해 환경 변수(.env)를 안전하게 로드하고 전역 설정 객체로 관리합니다.

pyproject.toml: 프로젝트 메타데이터와 패키지 의존성(Dependencies)을 정의하는 현대적인 파이썬 표준 설정 파일입니다. (UV 도구 호환)

uv.lock: 의존성 패키지의 정확한 버전을 잠그어(Lock) 팀원(또는 배포 환경) 간에 완벽히 동일한 라이브러리 환경을 보장합니다.
