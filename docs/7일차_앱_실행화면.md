# 7일차 앱 실행 화면 및 엔드포인트 연동 명세

- **설명**: FastAPI 앱의 루트(`/`) 경로에서 서빙되는 프론트엔드 대시보드 화면입니다.

## 2. 주요 Endpoints 동작 확인
- **인증(Auth) 및 사용자 관리 (`/api/users`)**: 
  - JWT 기반 회원가입 및 로그인 기능이 정상 동작합니다.
- **환자 관리 (`/api/patients`)**: 
  - 환자 정보 등록 및 조회 API 연동 완료.
- **AI 예측 (`/api/v1/predictions/predict`)**: 
  - 흉부 X-Ray 이미지를 받아 폐렴 예측 결과를 반환하는 AI 모델 파이프라인 연동 확인.

## 3. API 문서 검증
- FastAPI 자동 생성 Swagger UI (`/http://127.0.0.1:8000/docs`)를 통해 각 엔드포인트의 입출력 스키마를 검증 완료했습니다.
