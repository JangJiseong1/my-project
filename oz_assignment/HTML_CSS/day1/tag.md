# 📚 HTML 핵심 태그 요약 정돈 (Day 1)

## 1. 구조 및 메타데이터 관련 태그
* **`<head>` (문서 정보 영역)**
  * 웹페이지 화면에는 직접 보이지 않지만, 웹브라우저가 문서를 해석하는 데 필요한 정보(메타데이터)를 담는 공간입니다.
  * 주요 포함 요소: `<title>`, `<meta>`, `<link>` 등

* **`<body>` (본문 영역)**
  * 사용자가 브라우저 화면을 통해 **실제로 보게 되는 모든 콘텐츠**(텍스트, 이미지, 버튼 등)가 들어가는 핵심 공간입니다.

---

## 2. 텍스트 및 레이아웃 태그
* **`<p>` (Paragraph / 단락)**
  * 텍스트의 일반적인 **한 단락(문단)**을 만들 때 사용합니다.
  * 블록(Block) 요소로, 위아래로 여백이 생기고 자동으로 줄바꿈이 됩니다.

---

## 3. 목록(List) 관련 태그
* **`<ul>` (Unordered List / 순서 없는 목록)**
  * 순서가 중요하지 않은 목록을 만들 때 사용합니다. (글머리 기호: 점, 동그라미 등)
  * 내부 항목은 반드시 `<li>`(List Item) 태그로 감싸야 합니다.

* **`<ol>` (Ordered List / 순서 있는 목록)**
  * 순서가 중요한 목록을 만들 때 사용합니다. (숫자 1, 2, 3... 표시)
  * 내부 항목은 `<li>` 태그를 사용합니다.

---

## 4. 미디어 및 사용자 입력 태그
* **`<img>` (Image / 이미지 삽입)**
  * 웹페이지에 사진이나 그림을 삽입하는 태그입니다.
  * 닫는 태그가 없는 **빈 태그**이며, `src`(경로/주소)와 `alt`(대체 텍스트) 속성이 필수입니다.

* **`<input>` (입력 필드)**
  * 사용자로부터 텍스트, 비밀번호, 이메일 등 다양한 데이터를 입력받을 때 사용하는 폼 요소입니다.
  * `type` 속성에 따라 역할이 바뀝니다 (예: `type="text"`, `type="password"` 등).
