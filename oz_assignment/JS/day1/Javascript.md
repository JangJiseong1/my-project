📚 자바스크립트(JS) Day 1 핵심 개념 노트
1. 자바스크립트란 무엇인가?
역할: 웹페이지의 동적 기능과 상호작용을 담당하는 프로그래밍 언어입니다.

비유: HTML이 집의 구조(벽, 방)이고, CSS가 인테리어(벽지, 가구)라면, 자바스크립트는 집의 전등을 켜고, 문을 여닫는 등의 '기능과 행동'을 담당합니다.

2. 출력 방식 (console.log)
자바스크립트 코드가 잘 실행되고 있는지, 데이터가 잘 들어왔는지 확인(디버깅)할 때 가장 많이 쓰는 도구입니다.

브라우저 화면에는 보이지 않고, 개발자 도구의 콘솔(Console) 창에 결과가 출력됩니다.

JavaScript
console.log("안녕하세요, 자바스크립트 첫 수업입니다!");
3. 변수 (Variables)
데이터를 담아두는 '상자' 같은 공간입니다.

let: 값이 언제든지 바뀔 수 있는 변수를 선언할 때 사용합니다.

JavaScript
let age = 25;
age = 26; // 값 변경 가능
const: 값이 절대 바뀌지 않는(상수) 고정된 값을 선언할 때 사용합니다. (실무에서 값을 실수로 바꾸는 것을 방지하기 위해 가장 많이 쓰입니다.)

JavaScript
const birthYear = 2000;
// birthYear = 2001; (에러 발생!)
4. 주요 자료형 (Data Types)
데이터의 형태에 따라 구분되는 종류입니다.

문자열 (String): 텍스트 데이터 ("홍길동", '안녕하세요')

숫자 (Number): 정수 및 실수 (100, 3.14)

불리언 (Boolean): 참(true) 또는 거짓(false)의 논리 값

undefined / null: 값이 없거나 비어 있음을 나타내는 데이터형

5. 연산자 (Operators)
산술 연산자: +, -, *, /, %(나머지)

대입 연산자: =, +=, -= 등

비교 연산자: ===(값과 타입이 모두 같음), !==(같지 않음), >, < 등

팁: 자바스크립트에서는 동등 연산자(==)보다는 엄격한 비교 연산자(===)를 사용하는 것이 버그를 줄이는 좋은 습관입니다.
